Lecture 7: Responsive Web Design

Pages that fit every screen

Summary

This lecture teaches how to make pages adapt to phones, tablets and desktops using the viewport meta tag, relative units, flexible images and media queries.

Topics Covered:

  • Responsive Web Design
    • Fundamentals
      • Viewport meta tag
      • Relative units (%, em, rem)
      • Flexible images
    • Media Queries
      • Breakpoints
      • Mobile-first approach

Example Code:

<style>.r{background:#d6eaf8;padding:10px}
@media (max-width:600px){.r{background:#fadbd8}}</style>
<div class="r">Resize the window to see the color change.</div>

Output:

Resize the window to see the color change.
