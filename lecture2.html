Lecture 2: HTML Basics

Structure of a web page

Summary

This lecture explains how an HTML document is structured using tags, elements and attributes, and how headings, paragraphs, lists and links are written.

Topics Covered:

  • HTML Basics
    • Document Structure
      • DOCTYPE and html tag
      • head and body
    • Common Elements
      • Headings and paragraphs
      • Ordered and unordered lists
      • Links and images
    • Attributes
      • href and src
      • id and class

Example Code:

<h2>My Hobbies</h2>
<ul>
  <li>Coding</li>
  <li>Reading</li>
</ul>
<a href="#">Click here</a>

Output:

My Hobbies

  • Coding
  • Reading
Click here
