Lecture 4: Introduction to CSS

Styling web pages

Summary

This lecture introduces CSS and the three ways of adding it to a page: inline, internal and external. It also covers basic properties for colors, fonts and text.

Topics Covered:

  • Introduction to CSS
    • Ways to Add CSS
      • Inline CSS
      • Internal CSS
      • External CSS
    • Basic Properties
      • color and background
      • font-family and font-size
      • text-align

Example Code:

<p style="color:#1b4f72; font-size:18px;">This text is styled with CSS.</p>

Output:

This text is styled with CSS.
