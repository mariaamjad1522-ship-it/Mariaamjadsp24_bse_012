Lecture 3: HTML Forms and Media

Collecting input and embedding media

Summary

This lecture shows how to build forms to collect user input and how to embed images, audio and video in a page.

Topics Covered:

  • HTML Forms and Media
    • Forms
      • form tag, action and method
      • Text, password, radio, checkbox
      • Select and textarea
      • Submit button
    • Media
      • img tag
      • audio and video tags
      • iframe

Example Code:

<form>
  <label>Name: <input type="text"></label>
  <button type="button">Send</button>
</form>
