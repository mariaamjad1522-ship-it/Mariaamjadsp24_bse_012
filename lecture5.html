Lecture 5: CSS Selectors

Choosing which elements to style

Summary

This lecture explains how selectors target elements, from simple tag, class and id selectors to combinators and pseudo-classes.

Topics Covered:

  • CSS Selectors
    • Basic Selectors
      • Element selector
      • Class selector (.)
      • ID selector (#)
    • Advanced Selectors
      • Descendant and child
      • Group selector
      • Pseudo-classes like :hover

Example Code:

<style>.note{color:#b03a2e;font-weight:bold}</style>
<p class="note">Selected using a class.</p>

Output:

Selected using a class.
