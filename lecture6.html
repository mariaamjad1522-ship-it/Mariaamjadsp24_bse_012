Lecture 6: CSS Box Model & Layout

Spacing, sizing and positioning

Summary

This lecture covers the box model (content, padding, border, margin) and layout techniques such as display, position, flexbox and grid.

Topics Covered:

  • CSS Box Model & Layout
    • Box Model
